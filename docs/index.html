Service

御社専用のAIづくり

御社の業務に合わせて、
専用のAIの仕組みを開発します。

確認シートで御社の仕事を伺い、その中からAIに任せられる作業を見つけて、御社のやり方に合わせた仕組みとして開発します。

  1. 1御社の仕事を伺う確認シートで、仕事の流れ・社内の言葉・決まりごと・今の道具をお聞きします。
  2. 2AIに任せられる作業を見つける問い合わせの返事・議事録・見積書など、文章をつくる作業を選び出します。
  3. 3御社のやり方で仕組みにする社内の言葉・書式とルールに合わせた仕組みにし、その作業の手間を減らします。
  4. 4ほかの仕事も見直す同じ確認シートから、入力や返信など、手作業で続けている仕事も洗い出します。
  5. 5AIに任せられる作業を見つける請求書の入力・SNSの投稿・社内の質問対応など、くり返しの作業を選び出します。
  6. 6御社のやり方で仕組みにする読み取り・下書き・回答をAIに任せ、社員の方は確認するだけの形にします。

図は一例です。業種を問わず、御社の仕事に合わせてご提案します。

社内の言葉・書式に合わせた出力

社内の言葉や書式は、一般的なAIでは使いこなせません。御社の用語や書式に合わせて作るので、AIが作った文章の手直しが減ります。

社内ルールに沿った運用

「金額は社長の確認後に出す」などの確認の手順を、あらかじめ組み込みます。AIに任せる範囲も、御社と決めたうえで動かします。

今お使いのツールと連携

LINE・Excel・Gmailなどとつないで動かします。今お使いの道具に合わせて作るので、覚え直す負担を抑えられます。

    情報の扱い

    Security

    お客様の情報をお預かりする責任を、何より重く考えています。使うAIの選び方から、AIに送る前の伏せ方、消すまでの期間まで、決まりを定めて守ります。

    入力した内容は、AIの学習に使われません

    文章づくりには、米国Anthropic社のAI「Claude」を会社向けの契約で使います。同社の規約では学習に使われず、通常は30日以内に消されます。規約違反の疑いを調べる時などは、最長2年残ることがあります。

    電話番号・住所は、AIに送る前に機械で伏せます

    お問い合わせや口コミの本文から、電話番号・メールアドレス・住所を自動で「［電話番号］」などに置き換えてから、AIに渡します。機械で行うため完全ではなく、お名前は本文に残ることがあります。

    パスワードはお預かりしません

    設定が必要な時は、御社からご招待いただいた権限の範囲で作業します。投稿やメールの送信など最後の操作は、御社の担当の方が行います。

    お預かりした資料は、30日以内に消します

    写真やメモは、終了後30日以内に削除します。資料に書くお客様のお名前は「○○様」までです。

    詳しい決まりは「お客様の情報の扱いについて」（A4・1枚）にまとめ、ご契約の前にお渡しします。

    About Us

    はじめまして。COAXIL代表の高橋陽人です。「AIに、人間の魂を込める。」COAXILが掲げるこの言葉には、私がこの事業に懸ける思いのすべてが詰まっています。AIがどれほど進歩しても、導入しただけで会社が良くなるわけではありません。一社一社の仕事を深く理解し、そこで働く人のことを考え抜いて形にしてはじめて、AIは本当の力を発揮するのだと信じています。

    その力を最も役立てていただきたいのが、本業に懸命に向き合う中小企業の皆さまです。地域の暮らしを支えている会社ほど、問い合わせへの対応や議事録、社内の同じ質問への回答に時間を取られ、AIを調べて試す余裕すら持てずにいることが少なくありません。そうした会社のためにこそAIを生かしたいと考え、御社の進め方を一つひとつ伺い、御社専用の仕組みとしてお渡しする事業として、COAXILを立ち上げました。

    私が目指しているのは、仕組みを使ってくださる会社の皆さまが無理なく効率よく働けるようになり、生まれた時間をお客様に注ぐことで売り上げが伸び、そこで働く人が皆、喜べる状態です。これから一社でも多くの会社と手を取り合い、その喜びを全国に広げていくことが、COAXILの使命だと考えています。

    だからこそ、一社一社のお話は代表の私が直接伺い、どれほど小さなお困りごとにも真剣に向き合います。御社のためにならないと思うことはご提案いたしませんし、お引き受けした仕事は、導入後の見直しまで含めて、最後まで責任を持ってやり遂げます。業種や地域を問わず、まずは御社のお話をお聞かせください。
